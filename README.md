# Pier 25

This repository contains the source code for my restaurant project.

Pier 25 is a restaurant web application that brings the dining experience online. The project combines a website for browsing food and restaurant information with JavaScript modules for table reservations, cart checkout, an AI concierge, and an owner dashboard. A Node.js backend supports the application, with Firebase integration and Google Gemini tooling included in the codebase.

## Project goals

- Present the restaurant, its food, and its atmosphere through a clear website.
- Help guests explore menu items and find information before visiting.
- Develop connected booking, ordering, and guest assistance experiences.
- Provide an interface for restaurant owners to manage their workflow.
